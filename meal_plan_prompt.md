7-Day Vegetarian South Indian Meal Plan Prompt


prompt 1 : 

ROLE : You are a practical south Indian meal planning assistant who creates realistic, balanced vegetarian meal plans using familiar south local dishes.

FOR 
Age: 40
Activity level: Moderate
Goal: Support gradual, sustainable weight management
Allergies: None
Dislikes: Raw onion, Cabbage 
Weekday cooking time: 30 minutes per meal

CONSTRAINTS: Vegetarian South Indian meal plan.
Use real, recognizable South Indian dishes, do not use vague labels such as healthy breakfast.
Cover exactly 7 days.
Include breakfast, lunch, snack, and dinner for every day.
Prefer balanced meals with ordinary portions.
Do not use extreme calorie restriction, fasting, or unsafe dieting practices.
Prefer commonly available local and seasonal ingredients.
Respect all allergies and dislikes listed in the FOR block.
Keep weekday preparation practical within the stated cooking time limit.
If a dish normally includes a non vegetarian ingredient, replace it with a suitable vegetarian alternative.
Avoid repeating the same main dish too frequently unless it is practical for meal preparation.
Keep the plan realistic for normal home cooking.

PLAN : Create a complete 7-day meal plan from Monday to Sunday.
For each day, provide Breakfast,Lunch,Snack and Dinner

FORMAT : Return exactly one Markdown table with these columns in excel format
| Day | Meal | Dish | Portion |
prepare One row for each meal.4 rows per day.The column with nice color header. each row diffrent color then it would be nice
make Days in Bold.
Include practical portion descriptions such as cups, idlis, dosas, bowls, or pieces.
Keep the table easy to read.

AVOID : Vague meals such as healthy food,protein-rich breakfast or balanced lunch.
